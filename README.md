## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Mortal Shell II**. This single-player trainer provides optional gameplay enhancements for Mortal Shell II, including survivability toggles, resource management, weapon progression support, and improved control over Shell-based abilities. It is designed for offline use and can be enabled selectively to preserve the game's exploration and combat systems.

**Target Audience:** Suitable for solo players who want to explore Mortal Shell II more freely, experiment with its eight warrior Shells and weapon upgrades, reduce repeated resource gathering, or customize the difficulty of its demanding combat.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Launch the game normally and load a single-player save before activating movement options. Use speed controls only in open areas, as excessive values may interfere with platforming, scripted sequences, or level transitions. Disable the option before interacting with doors, ladders, elevators, or cinematic triggers.

### Tools & Inventory

Inventory options affect consumables, ammunition, and upgrade materials used during exploration. Open the inventory or equipment screen after activating a resource option so the game can refresh the displayed quantities. Avoid spending resources during save or loading transitions, and disable inventory changes before closing the game.

### World & Environment

Mortal Shell II features a compact interconnected world containing winding paths, hidden discoveries, lost warrior Shells, weaponry, upgrades, curiosities, and more than 80 dungeons. Movement and survivability options are useful for surveying optional routes, while progression options can reduce the need to revisit areas solely for materials.

### Combat & Weapons

Combat is agile and unrestricted by a stamina gauge. The game emphasizes timing, enemy posture, critical strikes, weapon upgrades, sidearms, and the unique abilities of possessed Shells. Activate defensive options before difficult encounters, and use damage or ammunition features selectively to avoid disrupting scripted boss phases and progression events.
